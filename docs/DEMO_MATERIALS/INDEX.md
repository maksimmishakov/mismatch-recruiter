## How to Use

1. Open DEMO_SCRIPT.md before demo
2. Follow the script exactly
3. Use QUICK_COMMANDS.sh for copy-paste
4. Keep SLIDES.md open for reference

## Pre-Demo Checklist

- [ ] `git checkout main`
- [ ] `docker-compose up -d`
- [ ] Wait 10 seconds for startup
- [ ] Run `docker ps` to verify
- [ ] Test `curl http://localhost:5000/health`
- [ ] Open GitHub Actions tab in browser
- [ ] Have README.md ready to show

## During Demo

1. Start with Introduction (0-1 min)
2. Show Infrastructure (1-2 min)
3. Run Health Check (2-3 min)
4. Show GitHub Actions (3-4 min)
5. Demo Code Tour (4-5 min)
6. Recap & Q&A (5-7 min)
