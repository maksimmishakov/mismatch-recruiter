# Mismatch Recruiter - User Guide

## Getting Started

### Registration
1. Navigate to the application
2. Click on "Register"
3. Enter your email and password
4. Click "Sign Up"

### Login
1. Click on "Login"
2. Enter your credentials
3. Click "Sign In"

## For Candidates

### Creating a Profile
1. Go to "My Profile"
2. Add your information
3. List your skills
4. Add experience
5. Save

### Viewing Job Matches
1. Go to "Matches"
2. Review matched jobs
3. Apply to jobs you're interested in

## For Recruiters

### Creating a Job
1. Go to "Post Job"
2. Enter job details
3. Set required skills
4. Set salary range
5. Publish

### Finding Candidates
1. Go to "Candidates"
2. Filter by skills
3. Review candidate profiles
4. Send job offers

## Troubleshooting

### Can't login
- Check your email and password
- Reset password if forgotten

### Can't find jobs
- Update your skills
- Adjust location preferences
