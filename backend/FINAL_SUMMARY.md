## 🚀 How to Get Started

### 1. Clone & Setup (5 minutes)
```bash
git clone https://github.com/maksimmishakov/mismatch-recruiter.git
cd mismatch-recruiter/backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Configure Database (2 minutes)
```bash
cp .env.example .env
nano .env  # Edit with your database credentials
python init_db.py
```

### 3. Run Backend (1 minute)
```bash
python app.py  # Runs on http://localhost:5000
```

### 4. Run Frontend (1 minute, separate terminal)
```bash
cd ../frontend
npm install
echo "VITE_APP_API_URL=http://localhost:5000/api" > .env.local
npm run dev  # Runs on http://localhost:5173
```

**Total Time: ~10 minutes**

For detailed instructions, see **QUICK_START.md**
